# Security

## Report a vulnerability

Please report it in private, not in a public issue or discussion.

- On GitHub: [Report a vulnerability](https://github.com/getminibrain/minibrain/security/advisories/new), under the
  Security tab of this repository. This is the quickest way.
- By email: hello@getminibrain.com.

Say which version you run, what you did, what happened and what you expected. A short script or the request that
shows the problem helps most.

## What happens next

- We aim to reply within a week.
- We tell you whether we can reproduce it and what we plan to do.
- Fixes go into the next release, and the release notes say so. We credit you unless you ask us not to.
- Please give us time to release a fix before you publish the details.

## Supported versions

Security fixes go into the latest release. Upgrade to get them: see
[Upgrades](https://getminibrain.com/docs/install/upgrades).
